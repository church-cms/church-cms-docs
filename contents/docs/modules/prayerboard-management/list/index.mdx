## Overview

The **Prayer Board List** page displays all prayer requests submitted by members and guests. Administrators can review each request and take appropriate action.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Prayer Board">
    From the main menu, click **Prayer Board**.

    ![Prayer Board Menu](/modules/prayerboard-management/prayer-board-menu.png)
  </StepItem>
  <StepItem title="View Prayer Board List">
    The Prayer Board list page will display all submitted prayer requests from members and guests.

    ![Prayer Board List](/modules/prayerboard-management/prayer-board-list.png)
  </StepItem>
</Step>

## Outcome

- All submitted prayer requests are visible in a list format for the administrator to review and manage.
