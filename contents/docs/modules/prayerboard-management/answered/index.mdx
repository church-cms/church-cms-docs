## Overview

The **Answered** tab displays prayer requests that have been fulfilled or answered. These serve as testimonies and encourage the congregation.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Prayer Board">
    From the main menu, click **Prayer Board**.
  </StepItem>
  <StepItem title="Select Answered tab">
    Click the **Answered** tab to view all prayer requests that have been answered.

    ![Answered Prayer Requests](/modules/prayerboard-management/prayer-answer-list.png)
  </StepItem>
</Step>

## Outcome

- All prayer requests with an **Answered** status are listed, marking them as fulfilled.
