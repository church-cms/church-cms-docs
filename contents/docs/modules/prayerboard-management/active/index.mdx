## Overview

The **Active** tab displays prayer requests that are currently being prayed for and are actively monitored by the administrator.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Prayer Board">
    From the main menu, click **Prayer Board**.
  </StepItem>
  <StepItem title="Select Active tab">
    Click the **Active** tab to view all currently active prayer requests.

    ![Active Prayer Requests](/modules/prayerboard-management/prayer-active-list.png)
  </StepItem>
</Step>

## Outcome

- All prayer requests with an **Active** status are listed, indicating they are currently being addressed.
