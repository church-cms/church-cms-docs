## Overview

The **End** tab displays prayer requests that have been closed or ended by the administrator. These requests are no longer active but are retained for record-keeping.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Prayer Board">
    From the main menu, click **Prayer Board**.
  </StepItem>
  <StepItem title="Select End tab">
    Click the **End** tab to view all prayer requests that have been ended.

    ![Ended Prayer Requests](/modules/prayerboard-management/prayer-end-list.png)
  </StepItem>
</Step>

## Outcome

- All prayer requests with an **End** status are listed, indicating they have been closed by the administrator.
