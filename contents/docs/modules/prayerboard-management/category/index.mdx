## Overview

The **Prayer Categories** page displays all categories used to classify prayer requests, such as Health, Family, Employment, and Financial. Administrators can view, add, edit, or delete categories from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Prayer Board">
    From the main menu, click **Prayer Board**.
  </StepItem>
  <StepItem title="Open Manage Categories">
    On the Prayer Board page, click **Manage Categories**.

    ![Manage Categories Button](/modules/prayerboard-management/prayer-category-button.png)
  </StepItem>
  <StepItem title="View Prayer Category List">
    The Prayer Categories page will display all existing categories along with their CSS class, prayer counts, and status.

    ![Prayer Category List](/modules/prayerboard-management/prayer-category-list.png)
  </StepItem>
</Step>

## Outcome

- All prayer categories are visible in a list format for the administrator to review and manage.
