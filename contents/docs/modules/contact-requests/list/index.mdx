## Overview

The **Contacts** page displays all contact requests submitted by members and guests, including their **Name**, **Mobile**, **Email**, and **Query**.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Contact Requests">
    From the main menu, click **Contact Requests**.

    ![Contact Requests Menu](/modules/contact-requests/contact-menu.png)
  </StepItem>
  <StepItem title="View Contact Requests List">
    The Contacts page will display all submitted contact requests. Use the **Search** field to find a specific request.

    ![Contact Requests List](/modules/contact-requests/contact-list.png)
  </StepItem>
</Step>

## Outcome

- All submitted contact requests are visible in a list format for the administrator to review.
