## Overview

Administrators can search the Contacts list to quickly find a specific contact request by name, mobile number, email, or query.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Contact Requests">
    From the main menu, click **Contact Requests**.
  </StepItem>
  <StepItem title="Enter Search Term">
    On the Contacts page, enter a keyword in the **Search** field at the top-right.

    ![Contact Requests Search](/modules/contact-requests/search-button.png)
  </StepItem>
  <StepItem title="View Search Results">
    The list will filter to show only contact requests matching the search term. Click **Reset** to clear the search and view all contact requests again.

    ![Contact Requests Search Results](/modules/contact-requests/search-results.png)
  </StepItem>
</Step>

## Outcome

- Only contact requests matching the search term are displayed for the administrator to review.
