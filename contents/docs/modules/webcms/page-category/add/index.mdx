## Overview

The **Add Category** page allows administrators to create a new category used to organize website pages.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Page Categories** section.
  </StepItem>
  <StepItem title="Click Add Category">
    Click the **Add Category** button to open the creation form.
  </StepItem>
  <StepItem title="Fill in the form">
    Complete the required fields — **Category Name**, **Slug**, **Description**, and **Sort Order** — in the New Page Category form.

    ![Add Category Form](/modules/cms-management/cms-page-add-category-form.png)
  </StepItem>
  <StepItem title="Click Save">
    Click **Save** to create the category.
  </StepItem>
</Step>

## Outcome

- The new category is created and appears in the Page Categories list, ready to be assigned to website pages.
