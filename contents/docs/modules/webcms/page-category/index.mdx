## Overview

The **Page Categories** page displays all categories used to organize website pages, along with their slug, description, order, and status. Administrators can review and manage page categories from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then select **Page Categories**.

    ![Page Categories Menu](/modules/cms-management/cms-page-category-menu.png)
  </StepItem>
  <StepItem title="View Page Categories List">
    The Page Categories page will display all categories with their Name, Slug, Description, Order, and Status.

    ![Page Categories List](/modules/cms-management/cms-page-category-list.png)
  </StepItem>
</Step>

## Outcome

- All page categories are listed for the administrator to review and manage.
