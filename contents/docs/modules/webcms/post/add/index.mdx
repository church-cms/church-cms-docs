## Overview

The **Add Post** page allows administrators to create a new post to publish on the church website.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Posts** section.
  </StepItem>
  <StepItem title="Click Add Post">
    Click the **Add Post** button to open the creation form.

    ![Add Post Button](/modules/cms-management/cms-post-add-button.png)
  </StepItem>
  <StepItem title="Fill in the form">
    Complete the required fields — **Title** and **Description** — and optionally add an **Attachment** and **Tag Name**. Enable **Post Later** to schedule the post for a future date.

    ![Add Post Form](/modules/cms-management/cms-post-add-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to publish the post.
  </StepItem>
</Step>

## Outcome

- The new post is created and appears in the Posts list, ready to be viewed on the website.
- The post is published on the website's **Blog** page for visitors to view.

![Blog Page](/modules/cms-management/cms-post-view-user.png)
