## Overview

The **Edit Post** page allows administrators to update the details of an existing website post.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Posts** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Posts list, click the **Edit** button on the post you want to update.

    ![Edit Post Button](/modules/cms-management/cms-post-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing **Title**, **Description**, and **Attachment** pre-filled. Update the required fields as needed.

    ![Edit Post Form](/modules/cms-management/cms-post-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The post details are updated and the changes are reflected immediately in the Posts list.
