## Overview

The **Delete Post** feature allows administrators to permanently remove a post that is no longer needed.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Posts** section.
  </StepItem>
  <StepItem title="Click Delete">
    In the Posts list, click the **Delete** button on the post you want to remove.

    ![Delete Post Button](/modules/cms-management/cms-post-delete-button.png)
  </StepItem>
  <StepItem title="Confirm Deletion">
    A confirmation dialog will appear. Click **OK** to permanently delete the post.

    ![Delete Confirmation](/modules/cms-management/cms-post-delete-confirm.png)
  </StepItem>
</Step>

## Outcome

- The post is permanently removed and will no longer appear in the Posts list.

<Note type="info">
  This action cannot be undone. Ensure the post is no longer needed before deleting.
</Note>
