## Overview

The **Edit FAQ** page allows administrators to update the details of an existing question and answer.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **FAQ** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the FAQ list, click the **Edit** button on the question you want to update.

    ![Edit FAQ Button](/modules/cms-management/cms-faq-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing **Faq Category**, **Question**, **Answer**, and **Order** pre-filled. Update the required fields as needed.

    ![Edit FAQ Form](/modules/cms-management/cms-faq-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The FAQ details are updated and the changes are reflected immediately in the FAQ list.
