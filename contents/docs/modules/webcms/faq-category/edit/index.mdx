## Overview

The **Edit FAQ Category** page allows administrators to update the details of an existing FAQ category.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **FAQ Categories** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the FAQ Categories list, click the **Edit** button on the category you want to update.
  </StepItem>
  <StepItem title="Update the form">
    The Edit FAQ Category form will open with the existing **Category Name** and **Status** pre-filled. Update the required fields as needed.

    ![Edit FAQ Category Form](/modules/cms-management/cms-faq-edit-category-form.png)
  </StepItem>
  <StepItem title="Click Save Changes">
    Click **Save Changes** to save the changes.
  </StepItem>
</Step>

## Outcome

- The category details are updated and the changes are reflected immediately in the FAQ Categories list.
