## Overview

The **Add Category** page allows administrators to create a new category used to organize frequently asked questions.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **FAQ Categories** section.
  </StepItem>
  <StepItem title="Click Add Category">
    Click the **Add Category** button to open the creation form.
  </StepItem>
  <StepItem title="Fill in the form">
    Enter the **Category Name** in the New FAQ Category form.

    ![Add FAQ Category Form](/modules/cms-management/cms-faq-add-category-form.png)
  </StepItem>
  <StepItem title="Click Save">
    Click **Save** to create the category.
  </StepItem>
</Step>

## Outcome

- The new category is created and appears in the FAQ Categories list, ready to be assigned to FAQs.
