## Overview

The **FAQ Categories** page displays all categories used to organize frequently asked questions, along with their status. Administrators can review and manage FAQ categories from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then select **FAQ Categories**.

    ![FAQ Categories Menu](/modules/cms-management/cms-faq-category-menu.png)
  </StepItem>
  <StepItem title="View FAQ Categories List">
    The FAQ Categories page will display all categories with their Name and Status.

    ![FAQ Categories List](/modules/cms-management/cms-category-list.png)
  </StepItem>
</Step>

## Outcome

- All FAQ categories are listed for the administrator to review and manage.
