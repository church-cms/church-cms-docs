## Overview

The **Edit Widget** page allows administrators to update the details of an existing code snippet widget.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Code Snippets** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Code Snippets list, click the **Edit** button on the widget you want to update.

    ![Edit Widget Button](/modules/cms-management/cms-code-snippets-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The Edit Widget form will open with the existing **Page**, **Display Order**, **Position**, and **Content** pre-filled. Update the required fields as needed.

    ![Edit Widget Form](/modules/cms-management/cms-code-snippets-edit-form.png)
  </StepItem>
  <StepItem title="Click Update Widget">
    Click **Update Widget** to save the changes.
  </StepItem>
</Step>

## Outcome

- The widget details are updated and the changes are reflected immediately on the public site.
