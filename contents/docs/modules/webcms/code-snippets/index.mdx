## Overview

The **Code Snippets** page lets administrators define reusable HTML/CSS/JS widgets once and embed them anywhere on the website using an embed tag. Administrators can review and manage all code snippets from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then select **Code Snippets**.

    ![Code Snippets Menu](/modules/cms-management/cms-code-snippets-menu.png)
  </StepItem>
  <StepItem title="View Code Snippets List">
    The Code Snippets page will display all widgets with their embed tag and HTML content, grouped by the page they belong to.

    ![Code Snippets List](/modules/cms-management/cms-code-snippets-list.png)
  </StepItem>
</Step>

## Outcome

- All code snippets are listed for the administrator to review, copy, and manage.
