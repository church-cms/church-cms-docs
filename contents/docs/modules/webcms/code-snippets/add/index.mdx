## Overview

The **Add Widget** page allows administrators to create a new reusable HTML/CSS/JS widget that renders on a chosen page of the website.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Code Snippets** section.
  </StepItem>
  <StepItem title="Click Add Snippet">
    Click the **Add Snippet** button to open the creation form.

    ![Add Snippet Button](/modules/cms-management/cms-code-snippets-add-button.png)
  </StepItem>
  <StepItem title="Fill in the form">
    Select the **Page**, **Display Order**, and **Position**, then enter the widget's **HTML / CSS / JS** content.

    ![Add Widget Form](/modules/cms-management/cms-code-snippets-add-form.png)
  </StepItem>
  <StepItem title="Click Save Widget">
    Click **Save Widget** to create the widget.

    ![Widget Added](/modules/cms-management/cms-code-snippets-add-success.png)
  </StepItem>
</Step>

## Outcome

- The new widget is created and appears in the Code Snippets list with its embed tag, ready to be copied into any page.
- The widget renders on the selected page of the website for visitors to view.

![Widget on Website](/modules/cms-management/cms-code-snippets-view-user.png)
