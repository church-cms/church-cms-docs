## Overview

The **Add Page** page allows administrators to create a new website page with its content, navigation, and SEO details.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Pages** section.
  </StepItem>
  <StepItem title="Click Add Page">
    Click the **Add Page** button to open the creation form.

    ![Add Page Button](/modules/cms-management/cms-page-add-button.png)
  </StepItem>
  <StepItem title="Fill in the form">
    Complete the required fields — **Page Name**, **Category**, **Slug**, **Layout Template**, **Cover Image**, and **Description** — across the **Page**, **Content**, **Navigation**, and **SEO** tabs.

    ![Add Page Form](/modules/cms-management/cms-page-add-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to create the page.

    ![Page Added](/modules/cms-management/cms-page-add-success.png)
  </StepItem>
</Step>

## Outcome

- The new page is created and appears in the Pages list, ready to be published on the website.

![Pages List](/modules/cms-management/cms-page-success.png)
