## Overview

The **Edit Page** page allows administrators to update the details of an existing website page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Pages** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Pages list, click the **Edit** button on the page you want to update.

    ![Edit Page Button](/modules/cms-management/cms-page-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing page details pre-filled across the **Page**, **Content**, **Navigation**, **SEO**, and **Versions** tabs. Update the required fields as needed.

    ![Edit Page Form](/modules/cms-management/cms-page-edit-form.png)
  </StepItem>
  <StepItem title="Click Save Changes">
    Click **Save Changes** to update the page.
  </StepItem>
</Step>

## Outcome

- The page details are updated and the changes are reflected immediately in the Pages list.
