## Overview

The **Delete Page** feature allows administrators to permanently remove a website page that is no longer needed.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Pages** section.
  </StepItem>
  <StepItem title="Click Delete">
    In the Pages list, click the **Delete** button on the page you want to remove.

    ![Delete Page Button](/modules/cms-management/cms-page-delete-button.png)
  </StepItem>
  <StepItem title="Confirm Deletion">
    A confirmation dialog will appear. Click **Delete** to permanently remove the page.

    ![Delete Confirmation](/modules/cms-management/cms-page-delete-confirm.png)
  </StepItem>
</Step>

## Outcome

- The page is permanently removed and will no longer appear in the Pages list.

<Note type="info">
  This action cannot be undone. Ensure the page is no longer in use before deleting.
</Note>
