## Overview

The **View Page** feature allows administrators to preview how a website page appears to visitors on the live site.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then navigate to the **Pages** section.
  </StepItem>
  <StepItem title="Click View">
    In the Pages list, click the **View** button on the page you want to preview.

    ![View Page Button](/modules/cms-management/cms-page-view-button.png)
  </StepItem>
  <StepItem title="Review the Page">
    The page opens on the live website, displaying its content as visitors will see it.

    ![Page Preview](/modules/cms-management/cms-page-user-view.png)
  </StepItem>
</Step>

## Outcome

- The selected page is displayed on the live website for the administrator to review.
