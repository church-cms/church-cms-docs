## Overview

The **Pages** page displays all website pages created in the system, along with their cover image, category, description, and likes. Administrators can review and manage pages from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open WebCMS">
    From the main menu, click **WebCMS**, then select **Pages**.

    ![Pages Menu](/modules/cms-management/cms-page-menu.png)
  </StepItem>
  <StepItem title="View Pages List">
    The Pages page will display all website pages with their Cover, Page Name, Category, Description, and Likes.

    ![Pages List](/modules/cms-management/cms-page-list.png)
  </StepItem>
</Step>

## Outcome

- All website pages are listed for the administrator to review and manage.
