## Overview

The **Event List** page displays all scheduled events in the system. Administrators can view, edit, or delete any event from this page. Events can be filtered and searched to quickly locate specific entries.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.

    ![Events Menu](/modules/events-calendar/event-menu.png)
  </StepItem>
  <StepItem title="View the Event List">
    The event list will be displayed showing all scheduled events with their details.

    ![Event List](/modules/events-calendar/event-list.png)
  </StepItem>
</Step>

## Available Actions

| Action | Description |
|--------|-------------|
| **+ Add Event** | Opens the form to create a new event. |
| **Edit** | Opens the event edit form to update its details. |
| **Delete** | Permanently removes the event from the system. |

## Search & Reset

- Use the **Search** bar to find an event by name.
- Click **Reset** to clear the search and return to the full list.

<Note type="info">
  Events are displayed in the calendar view as well. Switch to the Calendar tab to see events by date.
</Note>
