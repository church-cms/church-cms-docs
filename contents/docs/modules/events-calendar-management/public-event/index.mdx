## Overview

A **Public Event** is visible to all members and can be announced through the member application. It appears on the calendar and members receive notifications about it.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.
  </StepItem>
  <StepItem title="Create a Public Event">
    Click the **+ Add Event** button and select **Public Event** from the options.
  </StepItem>
  <StepItem title="Enter the required details">
    A new event form will open. Fill in the following fields:

    - **Title** *(required)* — Enter the event title.
    - **Description** — Enter a brief description of the event.
    - **Repeats** — Set whether the event repeats (None, Daily, Weekly, Monthly).
    - **Location** — Enter the event venue or location.
    - **Event Category** — Select the category for the event.
    - **Organized By** — Enter the name of the organizer.
    - **Start Date & Time** *(required)* — Set the event start date and time.
    - **End Date & Time** *(required)* — Set the event end date and time.

    ![Create Public Event Form](/modules/events-calendar/create-public-event.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save and create the public event.
  </StepItem>

    
</Step>

## Outcome

- The public event will be created successfully.
- It will appear in the event list and on the calendar, visible to all members.
- Members will receive notifications via the member application.

![Public Event List](/modules/events-calendar/event-public-list.png)

<Note type="info">
  Public events are visible to all members. Ensure all event details are accurate before submitting.
</Note>
