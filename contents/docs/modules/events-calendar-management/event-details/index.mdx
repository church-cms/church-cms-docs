## Overview

The **Event Details** page displays complete information for a scheduled event. Administrators can view the event description, manage photos, track attendance, and add notes — all from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.
  </StepItem>
  <StepItem title="Click View on an Event">
    In the event list, click the **View** button on the event row to open its details page.

    ![Event Details Button](/modules/events-calendar/event-details-button.png)
  </StepItem>
  <StepItem title="View Event Details">
    The event details page will open showing the full event information including title, description, date, time, location, category, and organizer.

    ![Event Details](/modules/events-calendar/event-details.png)
  </StepItem>
</Step>

---

## Event Sections

### Photos

The **Photos** section displays all images uploaded for the event. Administrators can add or remove event photos.

![Event Photos](/modules/events-calendar/event-photos.png)

---

### Attendance

The **Attendance** section shows the list of members who attended the event. Administrators can mark or update attendance records.

![Event Attendance](/modules/events-calendar/event-attendance.png)

---

### Notes

The **Notes** section allows administrators to add internal notes related to the event for reference.

![Event Notes](/modules/events-calendar/event-notes.png)

---
<Note type="info">
  Use the Photos, Attendance, and Notes sections to keep a complete record of each event after it takes place.
</Note>
