## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.
  </StepItem>
  <StepItem title="Click Edit on an Event">
    In the event list, click the **Edit** button on the event row you want to update.

    ![Edit Event Button](/modules/events-calendar/event-edit-button.png)
  </StepItem>
  <StepItem title="Update the event details">
    The event edit form will open with the current details pre-filled. Update any of the following fields as needed:

    - **Title** — Modify the event title.
    - **Description** — Update the event description.
    - **Repeats** — Change the repeat schedule.
    - **Location** — Update the venue or location.
    - **Event Category** — Change the event category.
    - **Organized By** — Update the organizer name.
    - **Start Date & Time** — Change the event start date and time.
    - **End Date & Time** — Change the event end date and time.

    ![Edit Event Form](/modules/events-calendar/event-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the updated event details.
  </StepItem>
  <StepItem title="Event updated">
    The event will be updated and the changes reflected in the event list and calendar.

    ![Event Updated](/modules/events-calendar/event-edit-success.png)
  </StepItem>
</Step>

## Outcome

- The event details will be updated successfully.
- The updated information will be reflected immediately in the event list and calendar view.
