## Overview

The **Search** feature in the Event List allows administrators to quickly find events by entering a category name or keyword. Matching results are displayed instantly.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.
  </StepItem>
  <StepItem title="Enter a search term">
    In the **Search** bar at the top of the event list, type the event category name or keyword you want to find.

    ![Event Category Search](/modules/events-calendar/event-category-search.png)
  </StepItem>
  <StepItem title="View search results">
    The event list will update to show only the events matching the search term.

    ![Event Category Search Result](/modules/events-calendar/event-category-search-result.png)
  </StepItem>
  <StepItem title="Reset the search">
    Click **Reset** to clear the search and return to the full event list.
  </StepItem>
</Step>

## Outcome

- Only events matching the entered keyword or category will be displayed.
- Click **Reset** at any time to restore the complete event list.

<Note type="info">
  Search works across event titles and categories. Use it to quickly locate events without scrolling through the full list.
</Note>
