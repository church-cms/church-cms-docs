## Overview

A **Private Event** is visible only to internal members and administrators. It will appear on the calendar but is not publicly accessible.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.
  </StepItem>
  <StepItem title="Create a Private Event">
    Click the **+ Add Event** button and select **Private Event** from the options.
  </StepItem>
  <StepItem title="Enter the required details">
    A new event form will open. Fill in the following fields:

    - **Title** *(required)* — Enter the event title.
    - **Description** — Enter a brief description of the event.
    - **Repeats** — Set whether the event repeats (None, Daily, Weekly, Monthly).
    - **Location** — Enter the event venue or location.
    - **Event Category** — Select the category for the event.
    - **Organized By** — Enter the name of the organizer.
    - **Start Date & Time** *(required)* — Set the event start date and time.
    - **End Date & Time** *(required)* — Set the event end date and time.

    ![Create Private Event Form](/modules/events-calendar/create-private-event.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save and create the private event.
  </StepItem>
</Step>

## Outcome

- The private event will be created successfully.
- It will appear in the event list and on the calendar, visible only to administrators and internal members.

![Private Event List](/modules/events-calendar/private-event-list.png)

![Private Event List](/modules/events-calendar/event-private-success.png)

<Note type="info">
  Private events are not visible to the public. Only logged-in members with appropriate access can view them.
</Note>
