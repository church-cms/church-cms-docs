## Overview

The **Calendar** view displays all scheduled church events in a monthly calendar layout. Administrators can quickly see which dates have events, navigate between months, and access event details directly from the calendar.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Events / Calendar">
    From the main menu, click **Events / Calendar**.
  </StepItem>
  <StepItem title="View the Calendar">
    The calendar will open showing the current month. Events are displayed on their scheduled dates.

    ![Calendar Overview](/modules/events-calendar/calendar-overview.png)
  </StepItem>
</Step>

## Calendar Features

- **Monthly View** — Displays all events for the current month on a date grid.
- **Event Indicators** — Dates with scheduled events are highlighted with the event name.
- **Month Navigation** — Use the previous and next arrows to move between months.
- **Add Event** — Click the **+ Add Event** button to create a new event directly from the calendar page.

<Note type="info">
  Click on any event shown on the calendar to view its full details.
</Note>
