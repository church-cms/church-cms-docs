## Overview

The **Donation Search** feature allows administrators to filter donation records by status, making it easier to find specific contributions.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Offerings">
    From the main menu, click **Offerings**.
  </StepItem>
  <StepItem title="Click Search">
    On the Donation List page, click the **Search** button to open the search filters.

    ![Search Button](/modules/offerings/offering-donation-search-button.png)
  </StepItem>
  <StepItem title="Filter by Status">
    Select the desired status from the filter options to narrow down the donation records.

    ![Search by Status](/modules/offerings/offering-donation-search-status.png)
  </StepItem>
</Step>

## Outcome

- The donation list is filtered to show only records matching the selected status.
