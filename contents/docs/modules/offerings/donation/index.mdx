## Overview

The **Donation List** page displays all offering donations submitted by members and guests. Administrators can review contribution records from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Offerings">
    From the main menu, click **Offerings**.

    ![Offerings Menu](/modules/offerings/offering-donation-menu.png)
  </StepItem>
  <StepItem title="View Donation List">
    The Donation List page will display all submitted offering donations from members and guests.

    ![Donation List](/modules/offerings/offering-donation-list.png)
  </StepItem>
</Step>

## Outcome

- All submitted donations are visible in a list format for the administrator to review and manage.
