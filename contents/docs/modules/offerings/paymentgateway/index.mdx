## Overview

The **Payment Gateway** page displays all configured payment gateways used to process offering donations. Administrators can review and manage available payment gateways from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Offerings">
    From the main menu, click **Offerings**, then navigate to the **Payment Gateway** section.

    ![Payment Gateway Menu](/modules/offerings/offering-paymentgateway-menu.png)
  </StepItem>
  <StepItem title="View Payment Gateway List">
    The Payment Gateway list page will display all configured gateways available for processing donations.

    ![Payment Gateway List](/modules/offerings/offering-paymentgateway-list.png)
  </StepItem>
</Step>

## Outcome

- All configured payment gateways are listed for the administrator to review and manage.
