## Overview

The **Edit Payment Gateway** page allows administrators to update the configuration details of an existing payment gateway.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Offerings">
    From the main menu, click **Offerings**, then navigate to the **Payment Gateway** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Payment Gateway list, click the **Edit** button on the gateway you want to update.

    ![Edit Button](/modules/offerings/offering-paymentgateway-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing configuration pre-filled. Update the required fields as needed.

    ![Edit Payment Gateway Form](/modules/offerings/offering-paymentgateway-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The payment gateway configuration is updated and the changes are reflected immediately in the Payment Gateway list.
