## Overview

The **Fund** page displays all configured offering funds. Administrators can review and manage funds that donations are allocated to from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Offerings">
    From the main menu, click **Offerings**, then navigate to the **Fund** section.

    ![Fund Menu](/modules/offerings/offering-fund-menu.png)
  </StepItem>
  <StepItem title="View Fund List">
    The Fund list page will display all configured offering funds available for donation allocation.

    ![Fund List](/modules/offerings/offering-fund-list.png)
  </StepItem>
</Step>

## Outcome

- All configured offering funds are listed for the administrator to review and manage.
