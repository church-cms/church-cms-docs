## Overview

The **Edit Fund** page allows administrators to update the details of an existing offering fund.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Offerings">
    From the main menu, click **Offerings**, then navigate to the **Fund** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Fund list, click the **Edit** button on the fund you want to update.

    ![Edit Button](/modules/offerings/offering-fund-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing fund details pre-filled. Update the required fields as needed.

    ![Edit Fund Form](/modules/offerings/offering-fund-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The fund details are updated and the changes are reflected immediately in the Fund list.
