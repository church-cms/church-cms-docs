## Overview

The **Activity Log** page displays a history of actions performed in the system, including the user's name, action title, description, date and time, and IP address.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Activity Logs">
    From the main menu, click **Activity Logs**.

    ![Activity Logs Menu](/modules/activitylogs/activitylog-menu.png)
  </StepItem>
  <StepItem title="View Activity Log List">
    The Activity Log page will display all recorded activities along with the **Name**, **Title**, **Description**, **Date and Time**, and **Ip** address. Use the pagination controls at the bottom to browse through older entries.

    ![Activity Log List](/modules/activitylogs/activitylog-list.png)
  </StepItem>
</Step>

## Outcome

- All recorded system activities are visible in a list format for the administrator to review.
