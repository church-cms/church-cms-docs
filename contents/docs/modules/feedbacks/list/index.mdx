## Overview

The **Feedbacks** page displays all feedback submitted by members, including the sender, category, message, and status.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Feedbacks">
    From the main menu, click **Feedbacks**.

    ![Feedbacks Menu](/modules/feedbacks/feedback-menu.png)
  </StepItem>
  <StepItem title="View Feedbacks List">
    The Feedbacks page will display all submitted feedback along with the **From**, **Category**, **Message**, and **Sent On** date.

    ![Feedbacks List](/modules/feedbacks/feedback-lists.png)
  </StepItem>
</Step>

## Outcome

- All submitted feedback is visible in a list format for the administrator to review.
