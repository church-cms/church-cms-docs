## Overview

Administrators can review a pending help request and either **Approve** or **Reject** it. Approved requests can also be set to automatically expire after a chosen period.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.
  </StepItem>
  <StepItem title="Click Review">
    On the **Pending** tab, click **Review** next to the help request you want to act on.

    ![Review Pending Help Request](/modules/help-requests/help-pending-review.png)
  </StepItem>
  <StepItem title="Select an Action">
    On the Review Help Request page, open the **Action** dropdown and choose **Approve** or **Reject**.

    ![Select Approve or Reject](/modules/help-requests/help-status-update.png)
  </StepItem>
  <StepItem title="Set Expiry (for Approve)">
    If you select **Approve**, choose an **Expire Within** duration for how long the request stays active.

    ![Approve Help Request](/modules/help-requests/help-status-approve.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the status change.
  </StepItem>
</Step>

## Outcome

- If **Approved**, the request moves to the **Approved** tab and will expire automatically after the selected duration.
- If **Rejected**, the request moves to the **Rejected** tab.
