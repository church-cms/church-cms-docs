## Overview

The **Approved** tab displays help requests that have been reviewed and approved by the administrator.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.

    ![Help Requests Menu](/modules/help-requests/help-menu.png)
  </StepItem>
  <StepItem title="Select Approved tab">
    Click the **Approved** tab to view all help requests that have been approved.

    ![Approved Help Requests](/modules/help-requests/help-approve-list.png)
  </StepItem>
</Step>

## Outcome

- All help requests with an **Approved** status are listed for the administrator to review.
