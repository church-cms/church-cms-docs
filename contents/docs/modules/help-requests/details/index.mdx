## Overview

Administrators can view the full details of a submitted help request, including the requester's name, title, description, contact details, and current status.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.
  </StepItem>
  <StepItem title="Click View">
    On any tab (**Pending**, **Approved**, **Rejected**, or **Closed**), click **View** next to a help request.
  </StepItem>
  <StepItem title="View Help Details">
    The Help Details page displays the **User Name**, **Title**, **Description**, **Contact Details**, and **Status** of the request.

    ![Help Details](/modules/help-requests/help-details.png)
  </StepItem>
</Step>

## Outcome

- The full details of the selected help request are displayed for the administrator to review.
