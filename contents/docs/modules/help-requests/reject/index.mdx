## Overview

The **Rejected** tab displays help requests that have been reviewed and rejected by the administrator.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.

    ![Help Requests Menu](/modules/help-requests/help-menu.png)
  </StepItem>
  <StepItem title="Select Rejected tab">
    Click the **Rejected** tab to view all help requests that have been rejected.

    ![Rejected Help Requests](/modules/help-requests/help-reject-list.png)
  </StepItem>
</Step>

## Outcome

- All help requests with a **Rejected** status are listed for the administrator to review.
