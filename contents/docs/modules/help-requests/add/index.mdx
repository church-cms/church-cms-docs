## Overview

Administrators (or members, on their behalf) can submit a new help request by providing a title, description, and contact number.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.
  </StepItem>
  <StepItem title="Click Add +">
    Click the **+ Add** button at the top-right of the page to open the add form.

    ![Add Help Button](/modules/help-requests/add-help-button.png)
  </StepItem>
  <StepItem title="Fill in the Help Request form">
    Enter the following details:

    - **Title** — a short title for the request.
    - **Description** — details about the help needed.
    - **Contact Number** — a number to reach the requester.

    ![Add Help Form](/modules/help-requests/add-help-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the request. A success message will confirm the request was added.

    ![Help Added Successfully](/modules/help-requests/add-help-success.png)
  </StepItem>
</Step>

## Outcome

- The new help request is added and listed under the **Pending** tab of the Help Requests page.

![Pending Help Requests](/modules/help-requests/help-pending-list.png)

## Member Panel

- The new help request is added and listed under the **help** menu page.

![Pending Help Requests](/modules/help-requests/user-help-list.png)
