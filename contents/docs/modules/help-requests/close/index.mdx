## Overview

The **Closed** tab displays help requests that have been completed and closed by the administrator.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.

    ![Help Requests Menu](/modules/help-requests/help-menu.png)
  </StepItem>
  <StepItem title="Select Closed tab">
    Click the **Closed** tab to view all help requests that have been closed.

    ![Closed Help Requests](/modules/help-requests/help-close-list.png)
  </StepItem>
</Step>

## Outcome

- All help requests with a **Closed** status are listed for the administrator to review.
