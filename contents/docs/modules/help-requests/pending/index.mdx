## Overview

The **Pending** tab displays help requests that have been submitted but not yet reviewed or acted upon by the administrator.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Help Requests">
    From the main menu, click **Help Requests**.

    ![Help Requests Menu](/modules/help-requests/help-menu.png)
  </StepItem>
  <StepItem title="Select Pending tab">
    Click the **Pending** tab to view all help requests awaiting review.

    ![Pending Help Requests](/modules/help-requests/help-pending-list.png)
  </StepItem>
</Step>

## Outcome

- All help requests with a **Pending** status are listed for the administrator to review and take action.
