## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Quotes / Bible Verse">
    From the main menu, click **Quotes / Bible Verse**.
  </StepItem>
  <StepItem title="Click Edit">
    In the list, click the **Edit** button on the entry you want to update.

    ![Edit Button](/modules/quotes-bibleverse/quotes-bible-editbutton.png)
  </StepItem>
  <StepItem title="Update the details">
    The edit form will open with the existing details pre-filled. Update the required fields:

    - **Type** — Change between Image or Text if needed.
    - **Quote / Verse** — Update the text content.
    - **Reference** — Update the source reference.
    - **Image** — Replace the existing image if applicable.

    ![Edit Quote Form](/modules/quotes-bibleverse/edit-quote.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The quote or Bible verse will be updated and the changes reflected immediately in the list.

![Edit Quote Success](/modules/quotes-bibleverse/edit-quote-sucess.png)
