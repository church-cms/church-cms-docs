## Overview

Administrators can add quotes and Bible verses in two formats — **Image** or **Text**. Both types are displayed to members across the platform.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Quotes / Bible Verse">
    From the main menu, click **Quotes / Bible Verse**.
  </StepItem>
  <StepItem title="Click Add +">
    Click the **Add +** button at the top-right of the page to open the add form.

    ![Add Button](/modules/quotes-bibleverse/quotes-bible-addbutton.png)
  </StepItem>
  <StepItem title="Add as Image">
    To add a quote or Bible verse as an **Image**:

    - Select the **Image** type.
    - Upload the image file using the file picker.

    ![Add Image Form](/modules/quotes-bibleverse/quotes-bible-addimage.png)
  </StepItem>
  <StepItem title="Add as Text">
    To add a quote or Bible verse as **Text**:

    - Select the **Text** type.
    - Enter the **Quote / Verse** content in the text field.
    - Enter the **Reference** (e.g. book, chapter, verse or author).

    ![Add Text Form](/modules/quotes-bibleverse/quotes-bible-addtext.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the entry.
  </StepItem>
</Step>

## Outcome

- The new quote or Bible verse will be added and listed on the Quotes & Bible Verse list page.

![Quote Added](/modules/quotes-bibleverse/quotes-bible-added.png)

<Note type="info">
  Use the **Image** type to display a designed graphic, and the **Text** type for plain scripture or quote content.
</Note>
