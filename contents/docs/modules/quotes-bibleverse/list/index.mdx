## Overview

The **Quotes & Bible Verse** list displays all inspirational quotes and Bible verses added to the system. Administrators can add new entries, edit existing ones, or delete them from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Quotes / Bible Verse">
    From the main menu, click **Quotes / Bible Verse**.

    ![Quotes Bible Verse Menu](/modules/quotes-bibleverse/quotes-bible-menu.png)
  </StepItem>
  <StepItem title="View the List">
    The list of all quotes and Bible verses will be displayed.

    ![Quotes Bible Verse List](/modules/quotes-bibleverse/quotes-bible-list.png)
  </StepItem>
</Step>

## Available Actions

| Action | Description |
|--------|-------------|
| **Add +** | Opens the form to create a new quote or Bible verse. |
| **Edit** | Opens the edit form to update an existing entry. |
| **Delete** | Permanently removes the quote or Bible verse. |

## Search & Reset

- Use the **Search** bar to find a quote or verse by keyword.
- Click **Reset** to clear the search and return to the full list.
