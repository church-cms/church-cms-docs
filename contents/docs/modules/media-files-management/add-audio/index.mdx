---

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Media Files">
    From the main menu, click **Media Files**.
  </StepItem>
  <StepItem title="Go to the Audio tab">
    Click the **Audio** tab to view all uploaded audio files. Then click the **Add Audio** button at the top-right corner.

    ![Audio List](/modules/mediafile-management/mediafiles-audio-list.png)
  </StepItem>
  <StepItem title="Fill in the audio details">
    The **Add Audio** form will open. Enter the following:

    - **Title** *(required)* — Enter a name for the audio file.
    - **Description** *(optional)* — Enter a brief description of the audio.
    - **Audio File** *(required)* — Click **Choose File** to select an audio file from your device.

    ![Add Audio Form](/modules/mediafile-management/mediafiles-audio-forms.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to upload the audio file.
  </StepItem>
  <StepItem title="Audio file added">
    The audio file will be uploaded and appear in the **Audio** tab of the Media Library.

    ![Audio Added](/modules/mediafile-management/mediafiles-audio-added.png)
  </StepItem>
</Step>

## Audio List Columns

| Column | Description |
|--------|-------------|
| **Name** | The title of the audio file. |
| **Description** | A short description of the audio. |
| **Added** | The date the audio was uploaded. |
| **Play** | Click to play the audio file directly. |
| **Download** | Click to download the audio file. |
| **Delete** | Permanently removes the audio file. |

## Outcome

- The uploaded audio will be available in the Media Library under the **Audio** tab.
- It can be attached to sermon chapters via the **Audio URL** field.

<Note type="info">
  Use the **Search** bar at the top-right to quickly find an audio file by name.
</Note>
