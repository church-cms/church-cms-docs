---

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Media Files">
    From the main menu, click **Media Files**.
  </StepItem>
  <StepItem title="Go to the Videos tab">
    Click the **Videos** tab to view all uploaded video files.

    ![Video List](/modules/mediafile-management/mediafiles-video-list.png)
  </StepItem>
  <StepItem title="Click Add Video">
    Click the **Add Video** button at the top-right corner of the page.

    ![Add Video Button](/modules/mediafile-management/mediafiles-video-button.png)
  </StepItem>
  <StepItem title="Fill in the video details">
    The **Add Video** form will open. Enter the following:

    - **Title** *(required)* — Enter a name for the video file.
    - **Description** *(optional)* — Enter a brief description of the video.
    - **Video File** *(required)* — Click **Choose File** to select a video file from your device.

    ![Add Video Form](/modules/mediafile-management/mediafiles-video-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to upload the video file.
  </StepItem>
  <StepItem title="Video file added">
    The video file will be uploaded and appear in the **Videos** tab of the Media Library.

    ![Video Added](/modules/mediafile-management/mediafiles-video-added.png)
  </StepItem>
</Step>

## Video List Columns

| Column | Description |
|--------|-------------|
| **Name** | The title of the video file. |
| **Description** | A short description of the video. |
| **Added** | The date the video was uploaded. |
| **View** | Click to view/play the video file directly. |
| **Download** | Click to download the video file. |
| **Delete** | Permanently removes the video file. |

## Outcome

- The uploaded video will be available in the Media Library under the **Videos** tab.
- It can be attached to sermon chapters via the **Video URL** field.

<Note type="info">
  Use the **Search** bar at the top-right to quickly find a video file by name.
</Note>
