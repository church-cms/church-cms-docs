## Overview

The **Media Library** displays all uploaded media files organized into three tabs: **Images**, **Audio**, and **Videos**. Administrators can browse, search, and delete files from this page. Files in the library can be selected when adding cover images or media across other modules.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Media Files">
    From the main menu, click **Media Files**.

    ![Media Files Menu](/modules/media-files-management/media-files-menu.png)
  </StepItem>
  <StepItem title="Browse the Media Library">
    The Media Library will open showing all uploaded files. Use the tabs to filter by type:

    - **Images** — View all uploaded images as thumbnails with their file names.
    - **Audio** — View all uploaded audio files.
    - **Videos** — View all uploaded video files.

    ![Media Library](/modules/mediafile-management/mediafiles-image-list.png)
  </StepItem>
</Step>

## Available Actions

| Action | Description |
|--------|-------------|
| **Add Image** | Upload a new image to the Media Library. |
| **X** (on card) | Permanently deletes the media file. |

## Search

- Use the **Search** bar at the top-right to find a file by name across the active tab.

<Note type="info">
  Files uploaded to the Media Library are available to pick when adding cover images in Sermons, Bulletins, Gallery, and other modules.
</Note>
