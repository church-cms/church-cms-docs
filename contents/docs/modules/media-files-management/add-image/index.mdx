## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Media Files">
    From the main menu, click **Media Files**.
  </StepItem>
  <StepItem title="Click Add Image">
    On the Media Library page, click the **Add Image** button at the top-right corner.

    ![Media Library](/modules/mediafile-management/mediafiles-image-list.png)
  </StepItem>
  <StepItem title="Fill in the image details">
    The **Add Image** form will open. Enter the following:

    - **Title** *(required)* — Enter a name for the image.
    - **Description** *(optional)* — Enter a brief description of the image.
    - **Image** *(required)* — Click **Choose File** to select an image file from your device.

    ![Add Image Form](/modules/mediafile-management/add-image-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to upload the image, or **Reset** to clear the form.
  </StepItem>
  <StepItem title="Image added">
   

    ![Image Added](/modules/mediafile-management/image-added.png)
  </StepItem>
</Step>

## Outcome

- The uploaded image will be available in the Media Library under the **Images** tab.
- It can be selected when picking a cover image in Sermons, Bulletins, Gallery, and other modules.

<Note type="info">
  Use the **Reset** button to clear all fields and start over without submitting.
</Note>
