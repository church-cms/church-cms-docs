## Overview

The **Maintenance Settings** page allows administrators to enable or disable maintenance mode for the ChurchCMS site. When maintenance mode is active, visitors will see a maintenance notice instead of the live site.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Settings">
    From the main menu, click **Settings**.
  </StepItem>
  <StepItem title="Select Maintenance">
    On the Settings page, click the **Maintenance** tab from the left-hand list.

    ![Maintenance Settings](/modules/settings/maintance-settings.png)
  </StepItem>
  <StepItem title="Configure Maintenance Mode">
    Toggle the maintenance mode on or off as required and configure any additional options shown on the page.
  </StepItem>
  <StepItem title="Click Save Changes">
    Click **Save Changes** to apply the settings.
  </StepItem>
</Step>

## Outcome

- Maintenance mode is enabled or disabled as configured. When enabled, the site will display a maintenance notice to all visitors until it is turned off.

<Note type="warning">
  Enabling maintenance mode will make the site inaccessible to regular users and members. Ensure you disable it once maintenance is complete.
</Note>
