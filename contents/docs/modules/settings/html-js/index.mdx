## Overview

The **HTML / JS Code** settings page allows administrators to inject custom HTML or JavaScript into the site's header or footer. This is useful for adding analytics scripts, custom tracking codes, or other third-party integrations.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Settings">
    From the main menu, click **Settings**.
  </StepItem>
  <StepItem title="Select HTML / JS Code">
    On the Settings page, click the **HTML / JS Code** tab from the left-hand list.

    ![HTML / JS Code Settings](/modules/settings/html-js-settings.png)
  </StepItem>
  <StepItem title="Enter Custom Code">
    Enter your custom HTML or JavaScript in the appropriate fields (e.g., Header Code or Footer Code).
  </StepItem>
  <StepItem title="Click Save Changes">
    Click **Save Changes** to apply the code to the site.
  </StepItem>
</Step>

## Outcome

- The custom HTML or JavaScript is injected into the site and will execute on every page load.

<Note type="warning">
  Only add trusted scripts and code. Malformed or malicious code can break the site or pose a security risk.
</Note>
