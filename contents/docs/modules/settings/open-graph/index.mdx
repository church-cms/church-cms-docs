## Overview

The **Open Graph Settings** page allows administrators to configure metadata used when the site is shared on social media platforms such as Facebook, Twitter, and LinkedIn. Setting up Open Graph ensures links shared from the site display a proper title, description, and image.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Settings">
    From the main menu, click **Settings**.
  </StepItem>
  <StepItem title="Select Open Graph">
    On the Settings page, click the **Open Graph** tab from the left-hand list.

    ![Open Graph Settings](/modules/settings/opengraph-settings.png)
  </StepItem>
  <StepItem title="Configure Open Graph Fields">
    Fill in the following fields:

    - **OG Title** — the title displayed when the site is shared on social media.
    - **OG Description** — a short description shown in social media previews.
    - **OG Image** — the image shown in link previews (recommended size: 1200 × 630 px).
  </StepItem>
  <StepItem title="Click Save Changes">
    Click **Save Changes** to apply the Open Graph settings.
  </StepItem>
</Step>

## Outcome

- The Open Graph metadata is saved and will be used when the site URL is shared on social media platforms, improving link preview appearance.
