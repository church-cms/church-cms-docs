## Overview

The **SEO Settings** page allows administrators to configure search engine optimization metadata for the site. Proper SEO settings help the church's website rank better in search engine results.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Settings">
    From the main menu, click **Settings**.
  </StepItem>
  <StepItem title="Select SEO">
    On the Settings page, click the **SEO** tab from the left-hand list.

    ![SEO Settings](/modules/settings/seo-settings.png)
  </StepItem>
  <StepItem title="Configure SEO Fields">
    Fill in the following fields:

    - **Meta Title** — the page title shown in browser tabs and search results.
    - **Meta Description** — a short description of the site displayed in search engine results.
    - **Meta Keywords** — relevant keywords to help search engines index the site.
  </StepItem>
  <StepItem title="Click Save Changes">
    Click **Save Changes** to apply the SEO settings.
  </StepItem>
</Step>

## Outcome

- The SEO metadata is saved and will be used by search engines to index and display the site in search results.
