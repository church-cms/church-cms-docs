## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Reports">
    From the main menu, click **Reports**.
  </StepItem>
  <StepItem title="Go to the Message History section">
    On the Reports page, locate the **Message History** card and click **Events**.

    ![Message History Events](/modules/reports/message-history-event%20-button.png)
  </StepItem>
  <StepItem title="View the Events Report">
    The **Events Reports** page opens, listing all messages sent for events.

    ![Events Report List](/modules/reports/message-history-event-reportlist.png)
  </StepItem>
  <StepItem title="Return to Reports">
    Click the back arrow at the top-left to return to the Reports page.
  </StepItem>
</Step>

## Events Report Columns

| Column | Description |
|--------|-------------|
| **Title** | The title of the event message that was sent. |
| **User Name** | The recipient's username or email address. |
| **Status** | The delivery status of the message (e.g. queue, sent). |
| **Sent Date** | The date the message was sent. |
| **Via** | The delivery channel used (e.g. Notification). |

<Note type="info">
  This report only lists message history for **Events**. Prayer Requests, Birthday, and Anniversary message history can be viewed the same way from their respective entries in the Message History section.
</Note>
