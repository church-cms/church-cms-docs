## Overview

The **Reports** page organizes available exports into sections. Each entry in the **Membership** and **Important Dates** sections shows a download icon that generates and downloads a CSV file when clicked, while entries in the **Message History** section open a detailed report list.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Reports">
    From the main menu, click **Reports**.

    ![Reports Menu](/modules/reports/reports-menu.png)
  </StepItem>
  <StepItem title="View the report sections">
    The Reports page will open showing the available report sections:

    - **Membership** — Active Members, Guest Members, Suspended / Expired Members.
    - **Message History** — Events, Prayer Requests, Birthday, Anniversary.
    - **Important Dates** — Birthday, Anniversary.

    ![Report List](/modules/reports/reports-list.png)
  </StepItem>
</Step>

## Available Sections

| Section | Reports |
|---------|---------|
| **Membership** | Active Members, Guest Members, Suspended / Expired Members |
| **Message History** | Events, Prayer Requests, Birthday, Anniversary |
| **Important Dates** | Birthday, Anniversary |

<Note type="info">
  Click the download icon next to a Membership or Important Dates report to export it as a CSV file. See [How to Download a Membership Report](/docs/modules/reports/download-membership-report) and [How to Download an Important Dates Report](/docs/modules/reports/download-important-dates-report) for detailed steps. For Message History, see [How to View a Message History Report](/docs/modules/reports/message-history-list).
</Note>
