---

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Reports">
    From the main menu, click **Reports**.
  </StepItem>
  <StepItem title="Go to the Message History section">
    On the Reports page, locate the **Message History** card and click the entry you want to view: **Events**, **Prayer Requests**, **Birthday**, or **Anniversary**.

    ![Message History Events](/modules/reports/message-history-event%20-button.png)
  </StepItem>
  <StepItem title="View the report list">
    The corresponding report page opens, listing all messages sent for that category.

    - **Events** — opens **Events Reports**.

      ![Events Report List](/modules/reports/message-history-event-reportlist.png)

    - **Prayer Requests** — opens **PrayerRequest Reports**.

      ![Prayer Request Report List](/modules/reports/reports-prayer-request-list.png)

    - **Birthday** — opens **Birthday Reports**.

      ![Birthday Report List](/modules/reports/reports-birthday-list.png)

    - **Anniversary** — opens **Anniversary Reports** in the same layout.

    If no messages have been sent for that category, the list shows **No records found**.
  </StepItem>
  <StepItem title="Return to Reports">
    Click the back arrow at the top-left to return to the Reports page.
  </StepItem>
</Step>

## Report Columns

| Column | Description |
|--------|-------------|
| **Title** | The title of the message that was sent. |
| **User Name** | The recipient's username or email address. |
| **Status** | The delivery status of the message (e.g. queue, sent). |
| **Sent Date** | The date the message was sent. |
| **Via** | The delivery channel used (e.g. Notification). |

<Note type="info">
  Events, Prayer Requests, Birthday, and Anniversary message history all use the same report layout — only the data source differs.
</Note>
