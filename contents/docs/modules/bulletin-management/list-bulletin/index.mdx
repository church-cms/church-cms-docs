## Overview

The **Bulletin List** page displays all bulletins created in the system, organized under **Monthly** and **Weekly** tabs. Each bulletin card shows its cover image, title, date, and a download link. Administrators can also edit or delete bulletins from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Bulletin">
    From the main menu, click **Bulletin**.

    ![Bulletin Menu](/modules/bulletin-management/bulletin-menu.png)
  </StepItem>
  <StepItem title="View the Bulletin List">
    The bulletin list will be displayed. Use the tabs to switch between:
    - **Monthly** — View all monthly bulletins.
    - **Weekly** — View all weekly bulletins.

    Each bulletin card shows:
    - **Cover Image** — Thumbnail of the bulletin.
    - **Title** — The bulletin name.
    - **Date** — The bulletin month/period.
    - **Download File** — Click to download the bulletin file.
    - **Edit** icon (pencil) — Click to edit the bulletin.
    - **X** button — Click to delete the bulletin.

    ![Bulletin List](/modules/bulletin-management/bulletin-list.png)
  </StepItem>
</Step>

## Available Actions

| Action | Description |
|--------|-------------|
| **Add +** | Opens the form to create a new bulletin. |
| **Download File** | Downloads the attached bulletin file. |
| **Edit** (pencil icon) | Opens the edit form for the bulletin. |
| **X** | Deletes the bulletin. |

## Search & Reset

- Use the **Search** bar at the top-right to find a bulletin by title.
- Click **Reset** to clear the search and return to the full list.

<Note type="info">
  Bulletins are grouped by their period date under the Monthly or Weekly tab.
</Note>
