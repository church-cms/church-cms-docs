## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Bulletin">
    From the main menu, click **Bulletin**.
  </StepItem>
  <StepItem title="Click the Edit icon">
    In the bulletin list, find the bulletin you want to update and click the **Edit** (pencil) icon on the bulletin card.

    ![Bulletin List Edit](/modules/bulletin-management/edit-bulletin-list.png)
  </StepItem>
  <StepItem title="Update the details">
    The **Edit Bulletin** form will open with the current details pre-filled. Update any of the following fields as needed:

    - **Bulletin Name** *(required)* — Modify the bulletin name.
    - **Year** *(required)* — Change the year from the dropdown.
    - **Type** *(required)* — Select **Monthly** or **Week** from the dropdown.
    - **Week** *(required if Type is Week)* — Select the week number from the dropdown.
    - **Cover Image** — Click **Change Image** to select a different image, or **Remove** to clear the current one.
    - **Bulletin File** — Click **View Current File** to preview the existing file. To replace it, click **Choose File** and upload a new PDF. Leave blank to keep the current file.

    ![Edit Bulletin Form](/modules/bulletin-management/edit-bulletin-form.png)
  </StepItem>
   <StepItem title="">
    
    ![Bulletin List Edit](/modules/bulletin-management/bulletin-updated.png)
  </StepItem>
  <StepItem title="Click Update">
    Click **Update** to save the changes, or **Cancel** to discard and go back.
  </StepItem>
</Step>

## Outcome

- The bulletin will be updated and the changes reflected immediately in the bulletin list.

<Note type="info">
  Upload a new PDF under **Bulletin File** only if you want to replace the existing file. Leave it blank to keep the current one.
</Note>
