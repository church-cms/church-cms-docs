## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Bulletin">
    From the main menu, click **Bulletin**.

    ![Bulletin Menu](/modules/bulletin-management/bulletin-menu.png)
  </StepItem>
  <StepItem title="Click Add +">
    Click the **Add +** button at the top-right of the Bulletins page.

    ![Add Bulletin Button](/modules/bulletin-management/add-bulletin-button.png)
  </StepItem>
  <StepItem title="Enter the required details">
    The **Create Bulletin** form will open. Fill in the following fields:

    - **Bulletin Name** *(required)* — Enter the name of the bulletin.
    - **Year** *(required)* — Select the year from the dropdown.
    - **Type** *(required)* — Select the bulletin type: **Monthly** or **Weekly**.
    - **Cover Image** *(required)* — Click **Pick from Media Library** to select a cover image.
    - **Bulletin File** *(required)* — Click **Choose File** to upload the bulletin document.

    ![Create Bulletin Form](/modules/bulletin-management/create-bulletin-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to create the bulletin, or **Cancel** to discard and go back.
  </StepItem>

 <StepItem title="">
    Bulletins page.

    ![Add Bulletin Button](/modules/bulletin-management/bulletin-added.png)
  </StepItem>
   <StepItem title="User web">
      Click the **Bulletin** List.
    ![Create Sermon Form](/modules/bulletin-management/user-bulletinlist.png)
  </StepItem>
</Step>

## Outcome

- The new bulletin will be created and listed under the corresponding **Monthly** or **Weekly** tab.
- Members will be able to view and download the bulletin file from the list.

<Note type="info">
  The bulletin type (Monthly or Weekly) determines which tab it appears under in the Bulletin List.
</Note>
