## Overview

The **Sermon List** page displays all sermons created in the system. Administrators can view, edit, or delete any sermon from this page. The list includes key details such as title, author, chapters, likes/dislikes, status, and the date the sermon was added.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Sermons">
    From the main menu, click **Sermons**.

    ![Sermons Menu](/modules/sermon-management/sermon-menu.png)
  </StepItem>
  <StepItem title="View the Sermon List">
    The sermon list will be displayed showing the following columns:
    - **Title** — The sermon title and its short description.
    - **Author** — The user who created the sermon.
    - **Chapters** — Number of chapters added to the sermon.
    - **Likes / Dislikes** — Member engagement count.
    - **Status** — Published or Draft status.
    - **Added On** — The date the sermon was created.
    - **Actions** — Options to **View**, **Edit**, or **Delete** the sermon.

    ![Sermon List](/modules/sermon-management/sermon-list.png)
  </StepItem>
</Step>

## Available Actions

| Action | Description |
|--------|-------------|
| **View** | Opens the sermon detail page. |
| **Edit** | Allows editing the sermon title, description, cover image, and chapters. |
| **Delete** | Permanently removes the sermon from the system. |

## Search & Reset

- Use the **Search** bar at the top-right to find a sermon by title.
- Click **Reset** to clear the search and return to the full list.

## Pagination

- The list displays **8 sermons per page**.
- Use the pagination controls at the bottom-right to navigate between pages.

<Note type="info">
  The sermon list shows all published sermons. Use the search bar to quickly locate a specific sermon by name.
</Note>
