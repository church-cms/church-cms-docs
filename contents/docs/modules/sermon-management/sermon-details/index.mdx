## Overview

After creating a sermon, you can manage its **Chapters** from the Sermon Details page. Each chapter can contain a video, audio, or PDF resource. Chapters are listed in order and can be edited or deleted individually.

## Step-by-Step Procedure

<Step>
  
  <StepItem title="Open Sermon Details">
    In the sermon list, click the chapter count number under the **Chapters** column, or click **Edit** and navigate to the chapters section.

    ![Sermon List Chapters](/modules/sermon-management/sermon-list-chapters.png)
  </StepItem>
  <StepItem title="View Chapters">
    The Chapters page will display all chapters added to the sermon. The table includes the following columns:

    - **#** — Chapter number in sequence.
    - **Chapter Title** — The title of the chapter.
    - **Date** — The date the chapter was added.
    - **Video** — A **Watch** link if a video is attached.
    - **Audio** — Indicates if an audio file is attached.
    - **PDF** — Indicates if a PDF file is attached.
    - **Actions** — Options to **Edit** or **Delete** the chapter.

    ![Sermon Chapters List](/modules/sermon-management/sermon-chapters-list.png)
  </StepItem>
  <StepItem title="Add a Chapter">
    Click the **+ Add Chapter** button at the top-right to add a new chapter to the sermon.
  </StepItem>
</Step>

## Available Actions

| Action | Description |
|--------|-------------|
| **+ Add Chapter** | Opens the form to create a new chapter for the sermon. |
| **Edit** | Opens the chapter edit form to update its title, date, or media files. |
| **Delete** | Permanently removes the chapter from the sermon. |

<Note type="info">
  A sermon chapter can include a video, audio file, or PDF — or any combination of these media types.
</Note>
