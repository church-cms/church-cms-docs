## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Sermons">
    From the main menu, click **Sermons**.

    ![Sermons Menu](/modules/sermon-management/sermon-menu.png)
  </StepItem>
  <StepItem title="Click Edit">
    In the sermon list, find the sermon you want to edit and click the **Edit** link in the Actions column.

    ![Edit Sermon Action](/modules/sermon-management/sermon-list-edit.png)
  </StepItem>
  <StepItem title="Update the details">
    The Edit Sermon form will open with the current details pre-filled. Update any of the following fields as needed:
    - **Title** — Modify the sermon title.
    - **Description** — Update the sermon description.
    - **Cover Image** *(optional)* — Click **Change Image** to select a different image from the Media Library, or click **Remove** to remove the current cover image.

    ![Edit Sermon Form](/modules/sermon-management/edit-sermon-form.png)
  </StepItem>
  <StepItem title="Click Update">
    Click the **Update** button to save the changes.
  </StepItem>
</Step>

## Outcome

- The sermon details will be updated and reflected immediately in the sermon list.

<Note type="info">
  The Cover Image field is optional. You can leave the existing image unchanged if no update is needed.
</Note>
