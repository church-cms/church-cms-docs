## Overview

The **Countries** page displays all countries available in the system, along with their short name, ISO code, telephone prefix, and status. Administrators can review and manage countries from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Master Data">
    From the main menu, click **Master Data**, then select **Countries**.

    ![Countries Menu](/modules/master-data/masterdata-country-menu.png)
  </StepItem>
  <StepItem title="View Countries List">
    The Countries page will display all countries with their Name, Short Name, ISO Code, Tel Prefix, and Status.

    ![Countries List](/modules/master-data/masterdata-country-list.png)
  </StepItem>
</Step>

## Outcome

- All countries are listed for the administrator to review and manage.
