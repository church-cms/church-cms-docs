## Overview

The **Cities** page displays all cities available in the system, along with their associated state, country, and status. Administrators can review and manage cities from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Master Data">
    From the main menu, click **Master Data**, then select **Cities**.

    ![Cities Menu](/modules/master-data/masterdata-city-menu.png)
  </StepItem>
  <StepItem title="View Cities List">
    The Cities page will display all cities with their Name, State, Country, and Status. Use the **All Countries** and **All States** filters to narrow the list.

    ![Cities List](/modules/master-data/masterdata-city-list.png)
  </StepItem>
</Step>

## Outcome

- All cities are listed for the administrator to review and manage.
