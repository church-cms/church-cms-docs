## Overview

The **Sent Messages** page displays all messages sent from the system, along with the batch ID, delivery mode, sent date, and status.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Messages">
    From the main menu, click **Messages**.

    ![Messages Menu](/modules/messages/messages-menu.png)
  </StepItem>
  <StepItem title="View Sent Messages List">
    The Sent Messages page will display all messages sent, along with their **Batch Id**, **Mode**, **Sent On** date, and **Status**. Use **Filter By Mode** to narrow the list by delivery mode.

    ![Sent Messages List](/modules/messages/send-message-list.png)
  </StepItem>
</Step>

## Outcome

- All sent messages are visible in a list format for the administrator to review.
