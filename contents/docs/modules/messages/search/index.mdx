## Overview

Administrators can filter the Sent Messages list by delivery **Mode** — such as **Mail**, **Notification**, or **Sms** — to quickly find messages sent through a specific channel.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Messages">
    From the main menu, click **Messages**.
  </StepItem>
  <StepItem title="Select a Mode">
    On the Sent Messages page, open the **Filter By Mode** dropdown and select **Mail**, **Notification**, or **Sms**.

    ![Filter By Mode](/modules/messages/search-mode.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to apply the filter.

    ![Search Messages](/modules/messages/search-messages.png)
  </StepItem>
</Step>

## Outcome

- The Sent Messages list is filtered to show only messages sent through the selected mode.
