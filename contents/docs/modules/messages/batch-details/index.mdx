## Overview

Each entry on the Sent Messages page represents a **Batch** of messages sent together. Administrators can click on a **Batch Id** or its **View** button to see the individual messages sent within that batch.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Messages">
    From the main menu, click **Messages**.
  </StepItem>
  <StepItem title="Click Batch Id or View">
    On the Sent Messages page, click the **Batch Id** link or the **View** button for the batch you want to inspect.

    ![Sent Messages Batch Id and View](/modules/messages/batchid-message-list.png)
  </StepItem>
  <StepItem title="View Batch Message List">
    The page will display all messages sent within that batch, along with the **To**, **Mode**, **Sent On**, and **Status** for each message.

    ![Batch Message List](/modules/messages/batchid-details-list.png)
  </StepItem>
</Step>

## Outcome

- All messages sent within the selected batch are listed for the administrator to review.
