# Sub Admin Profile

## Overview

The **Sub Admin Profile** page provides a complete view of a sub-admin's personal information, contact details, membership data, and role-based permissions. Administrators can manage account access and assign granular permissions from this page.

---

## Accessing the Sub Admin Profile

From the **Sub Admins** list, click on a sub-admin's name to open their profile page.

![Sub Admin Profile](/modules/sub-admin/sub-admin-detail.png)
![Sub Admin Profile](/modules/sub-admin/sub-admin-details.png)

---

## Profile Header

The top section of the profile displays the sub-admin's name and ID, along with three action buttons:

| Button | Description |
|--------|-------------|
| **Deactivate** | Deactivates the sub-admin account, preventing login. |
| **Reset Password** | Sends a password reset link to the sub-admin's email. |
| **Verify Email** | Sends an email verification request to the sub-admin. |

---

## Left Panel — Personal Details

The left panel shows the sub-admin's profile picture with an **Edit** button to update it, along with:

**Basic Information**
- **Date of Birth**
- **Occupation**
- **Gender**
- **Aadhaar Number**

**Contact Information**
- Address
- Phone Number
- Email Address

---

## Profile Tabs

The right panel contains multiple tabs for detailed information:

| Tab | Description |
|-----|-------------|
| **My Profile** | Shows Age, Membership Type, and Membership Start Date. |
| **Timeline** | Displays the activity timeline of the sub-admin. |
| **Family Tree** | Shows family relationships linked to the profile. |
| **Family** | Lists family members associated with the account. |
| **Messages** | Shows messages sent or received by the sub-admin. |
| **Notes** | Displays admin notes added to the profile. |

---

## Roles & Permissions

The **Roles & Permissions** section allows administrators to control what actions the sub-admin can perform across modules.

### Apply Role Preset

Select a predefined role from the **Apply Role Preset** dropdown and click **Apply** to assign all permissions for that role at once. Click **Clear All** to remove all permissions.

![Roles and Permissions](/modules/sub-admin/sub-admin-roles.png)



### Module-Level Permissions

Each module lists individual permissions that can be toggled on or off:

- Use **Toggle All** on the right of each module to enable or disable all permissions for that module at once.
- Individual checkboxes allow fine-grained control (e.g. **Create**, **Read**, **Update**, **View**).

**Example modules:**
- **Attendance** — Create Attendance, Read Attendance, Update Attendance
- **Bulletins** — Create Bulletins, Read Bulletins, View Bulletins
- **Events** — Create Events, Read Events, View Events

![Roles and Permissions](/modules/sub-admin/sub-admin-roles1.png)
![Roles and Permissions](/modules/sub-admin/sub-admin-rolesupdate.png)
![Roles and Permissions](/modules/sub-admin/sub-admin-user-menu.png)

<Note type="info">
  Changes to Roles & Permissions take effect immediately after saving. Always review permissions carefully before applying a role preset.
</Note>
