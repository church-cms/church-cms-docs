## Overview

The **Mailing List Details** page displays the full information of a specific mailing list, including its subscribers and configuration.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster">
    From the main menu, click **Email Blaster**, then navigate to the **Mailing List** section.
  </StepItem>
  <StepItem title="Click View">
    In the Mailing List, click the **View** button on the list you want to inspect.

    ![View Button](/modules/email-blaster/email-mailing-view-button.png)
  </StepItem>
  <StepItem title="Review Mailing List Details">
    The Mailing List Details page will display the full information for the selected mailing list.

    ![Mailing List Details](/modules/email-blaster/email-mailing-details.png)
  </StepItem>
</Step>

## Outcome

- The full details of the selected mailing list are displayed for the administrator to review.
