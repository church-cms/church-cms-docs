## Overview

The **Add Mailing List** page allows administrators to create a new mailing list to group subscribers for targeted email campaigns.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster">
    From the main menu, click **Email Blaster**, then navigate to the **Mailing List** section.
  </StepItem>
  <StepItem title="Click Add Mailing List">
    Click the **Add Mailing List** button to open the creation form.

    ![Add Mailing List Button](/modules/email-blaster/email-mailing-add-button.png)
  </StepItem>
  <StepItem title="Fill in the form">
    Complete the required fields in the Add Mailing List form.

    ![Add Mailing List Form](/modules/email-blaster/email-mailing-add-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to create the mailing list.
  </StepItem>
</Step>

## Outcome

- The new mailing list is created and appears in the Mailing List, ready to be used in email campaigns.

![Mailing List Updated](/modules/email-blaster/email-mailing-success-list.png)
