## Overview

The **Edit Mailing List** page allows administrators to update the details of an existing mailing list.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster">
    From the main menu, click **Email Blaster**, then navigate to the **Mailing List** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Mailing List, click the **Edit** button on the list you want to update.

    ![Edit Button](/modules/email-blaster/email-mailing-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing mailing list details pre-filled. Update the required fields as needed.

    ![Edit Mailing List Form](/modules/email-blaster/email-mailing-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The mailing list details are updated and the changes are reflected immediately in the Mailing List.
