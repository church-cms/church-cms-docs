## Overview

The **Mailing List** page displays all configured mailing lists used to group subscribers for targeted email campaigns. Administrators can review and manage mailing lists from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster">
    From the main menu, click **Email Blaster**, then navigate to the **Mailing List** section.

    ![Mailing List Menu](/modules/email-blaster/email-mailing-menu.png)
  </StepItem>
  <StepItem title="View Mailing List">
    The Mailing List page will display all configured mailing lists with their details.

    ![Mailing List](/modules/email-blaster/email-mailing-list.png)
  </StepItem>
</Step>

## Outcome

- All mailing lists are displayed for the administrator to review and manage.
