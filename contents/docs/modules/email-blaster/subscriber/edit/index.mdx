## Overview

The **Edit Subscriber** page allows administrators to update the details of an existing email subscriber.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster">
    From the main menu, click **Email Blaster**, then navigate to the **Subscriber** section.
  </StepItem>
  <StepItem title="Click Edit">
    In the Subscriber list, click the **Edit** button on the subscriber you want to update.

    ![Edit Button](/modules/email-blaster/email-subscriber-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing subscriber details pre-filled. Update the required fields as needed.

    ![Edit Subscriber Form](/modules/email-blaster/email-subscriber-edit-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The subscriber details are updated and the changes are reflected immediately in the Subscriber list.
