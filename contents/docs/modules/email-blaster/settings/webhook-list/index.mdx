## Overview

The **Webhooks** page displays all configured webhooks used to notify external systems about mailing list events. Administrators can review and manage the available webhooks from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster Settings">
    From the main menu, click **Email Blaster**, then click **Settings**, and select **Webhooks**.

    ![Webhooks Menu](/modules/email-blaster/email-settings-webhook-menu.png)
  </StepItem>
  <StepItem title="View Webhook List">
    The Webhooks page will display all configured webhooks with their Name, Mailing List, and Active status.

    ![Webhook List](/modules/email-blaster/email-settings-webhook-list.png)
  </StepItem>
</Step>

## Outcome

- All configured webhooks are listed for the administrator to review and manage.
