## Overview

The **Webhook Details** page displays the full configuration of a specific webhook, including its mailing list, URL, and handshake key.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster Settings">
    From the main menu, click **Email Blaster**, then click **Settings**, and select **Webhooks**.
  </StepItem>
  <StepItem title="Click View">
    In the Webhook list, click the **View** button on the webhook you want to inspect.
  </StepItem>
  <StepItem title="Review Webhook Details">
    The Webhook Details page will display the Name, Mailing List, URL, Handshake Key, and Status for the selected webhook.

    ![Webhook Details](/modules/email-blaster/email-settings-webhook-details.png)
  </StepItem>
</Step>

## Outcome

- The full details of the selected webhook are displayed for the administrator to review.
