## Overview

The **Add Webhook** page allows administrators to configure a new webhook to notify an external system when events occur on a mailing list.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster Settings">
    From the main menu, click **Email Blaster**, then click **Settings**, and select **Webhooks**.
  </StepItem>
  <StepItem title="Click Add">
    Click the **Add** button to open the creation form.

    ![Add Webhook Button](/modules/email-blaster/email-settings-webhook-add-button.png)
  </StepItem>
  <StepItem title="Fill in the form">
    Complete the required fields — **Title**, **Mailing List**, **URL**, **Handshake Key**, and **Active** — in the Add Webhook form.

    ![Add Webhook Form](/modules/email-blaster/email-settings-webhook-add-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the new webhook.

    ![Webhook Created](/modules/email-blaster/email-settings-webhook-success.png)
  </StepItem>
</Step>

## Outcome

- The new webhook is created and appears in the Webhook list, ready to notify the external system.
