## Overview

The **Create SMTP** page allows administrators to configure a new SMTP server used to send campaign and newsletter emails.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster Settings">
    From the main menu, click **Email Blaster**, then click **Settings**, and select **SMTPs**.
  </StepItem>
  <StepItem title="Click Add">
    Click the **Add** button to open the creation form.

    ![Add SMTP Button](/modules/email-blaster/email-settings-smtp-add-button.png)
  </StepItem>
  <StepItem title="Fill in the form">
    Complete the required fields — **Host**, **Port**, **User Name**, **Password**, **Encryption**, and **Active** — in the Create SMTP form.

    ![Create SMTP Form](/modules/email-blaster/email-settings-smtp-form.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the new SMTP configuration.

    ![SMTP Created](/modules/email-blaster/email-settings-smtp-success.png)
  </StepItem>
</Step>

## Outcome

- The new SMTP configuration is created and appears in the SMTP list, ready to be used for sending emails.
