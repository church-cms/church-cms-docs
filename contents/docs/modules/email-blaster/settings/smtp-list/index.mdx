## Overview

The **SMTP** page displays all configured SMTP servers used to send campaign and newsletter emails. Administrators can review and manage the available SMTP configurations from this page.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster Settings">
    From the main menu, click **Email Blaster**, then click **Settings**, and select **SMTPs**.

    ![SMTP Menu](/modules/email-blaster/email-settings-smtp-menu.png)
  </StepItem>
  <StepItem title="View SMTP List">
    The SMTP list page will display all configured SMTP servers with their Host, Port, Username, Password, Encryption, and Active status.

    ![SMTP List](/modules/email-blaster/email-settings-smtp-list.png)
  </StepItem>
</Step>

## Outcome

- All configured SMTP servers are listed for the administrator to review and manage.
