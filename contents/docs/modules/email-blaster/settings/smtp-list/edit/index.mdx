## Overview

The **Edit SMTP** page allows administrators to update the details of an existing SMTP configuration.

## Step-by-Step Procedure

<Step>
  <StepItem title="Login to the system">
    Login to the system using **Admin credentials**.
  </StepItem>
  <StepItem title="Open Email Blaster Settings">
    From the main menu, click **Email Blaster**, then click **Settings**, and select **SMTPs**.
  </StepItem>
  <StepItem title="Click Edit">
    In the SMTP list, click the **Edit** button on the SMTP configuration you want to update.

    ![Edit SMTP Button](/modules/email-blaster/email-settings-smtp-edit-button.png)
  </StepItem>
  <StepItem title="Update the form">
    The edit form will open with the existing SMTP details pre-filled. Update the required fields as needed.

    ![SMTP Updated](/modules/email-blaster/email-settings-smtp-updated.png)
  </StepItem>
  <StepItem title="Click Submit">
    Click **Submit** to save the changes.
  </StepItem>
</Step>

## Outcome

- The SMTP configuration is updated and the changes are reflected immediately in the SMTP list.
